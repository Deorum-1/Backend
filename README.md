# Backend

## Setup

1. Install dependencies with `npm install`.
2. Copy `.env.example` to `.env`.
3. In `.env`, replace the MongoDB URI placeholders with your connection details. The application reads the connection string from `MONGODB_URI`. Set `PORT` if you want to use a port other than `8000`.

## Run

Start the development server with `npm run dev`, or use `npm start`.
